Technical Highlights

9-State Status Engine

2× TEMP TABLE ENGINE=MEMORY รวม tray_discrepancies + tray_borrowed + tray_sold_borrowed → CASE WHEN คำนวณ 9 สถานะ (1,2,3,4,5,7,8,10,13)

3-Round Fuzzy Matching

R1: exact/substring · R2: keyword→กลุ่ม→ชื่อเต็ม · R3: ตัดคำนำหน้าเทียบชื่อสาขา · SESSION cache 5 min TTL

Shift-Aware Date

CASE WHEN HOUR(start_time) < 7 THEN DATE_SUB(in_date, INTERVAL 1 DAY)

Async Fire-and-Forget

cURL — CURLOPT_TIMEOUT_MS=2000 + CURLOPT_NOSIGNAL=1 trigger cron โดยไม่รอ response

ISO Week Cycle

getCycle() = ceil(ISO_WEEK / 4) → 1–13 cycle ต่อปี สำหรับ group ถาดซื้อ/ขาย

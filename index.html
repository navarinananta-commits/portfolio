Technical Highlights

9-State Status Engine

2× TEMP TABLE ENGINE=MEMORY รวม tray_discrepancies + tray_borrowed + tray_sold_borrowed แล้ว CASE WHEN คำนวณ 9 สถานะ (1,2,3,4,5,7,8,10,13)

3-Round Fuzzy Matching

R1: exact/substring · R2: keyword→กลุ่ม→ชื่อเต็ม · R3: ตัดคำนำหน้ากลุ่มเทียบชื่อสาขา จับคู่ destination → customer_code

Shift-Aware Date

CASE WHEN HOUR(start_time) < 7 THEN DATE_SUB(in_date, INTERVAL 1 DAY) ใน KPI และ report_summary

Async Fire-and-Forget

cURL CURLOPT_TIMEOUT_MS=2000, CURLOPT_NOSIGNAL=1 trigger cron_import หลัง upload โดยไม่รอ response

ISO Week Cycle

getCycle() ใน sold_tray.php: ceil(ISO_WEEK / 4) → 1–13 cycle ต่อปี ใช้ getCycleLabel() group รายการถาดซื้อ/ขายตามรอบ
